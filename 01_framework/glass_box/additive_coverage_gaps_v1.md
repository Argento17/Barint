# Additive Coverage Gaps — D4 Library v1

**Why this exists.** The D4 library (51 tiered rows + E120 pending) was built from hummus / maadanim /
bread only. Since then ~9 more shelves went live (cakes, cookies, chocolate, protein bars, snacks,
cereals, granola, juices, hard cheeses) carrying additives the library has never assessed. The E120
fill prompted a full re-scan. These are the gaps that genuinely warrant **owner-commissioned research**
(E120-style evidence pulls) — not a full E-number census. Tiers are NOT assigned here; they follow the
commissioned evidence. Detector wiring follows tier assignment.

## Commission priority

| # | Additive / class | Gap | Products / shelves | Urgency | What the research must establish |
|---|---|---|---|---|---|
| 1 | **E160b annatto** (colour) | absent from library + taxonomy | ~26 / cakes, cereals, cookies-coffee, hard cheeses | **High** | EFSA re-eval + documented hypersensitivity signal (urticaria / IgG pathway, distinct from IgE) + any over-exposure flag. The E120-analog for the cheese/baked shelf — likely `likely-neutral`, possibly `contested`; emphatically NOT `functional` like E162/E163. |
| 2 | **E220 sulphite family** (E220/221/222/223/224/225/228) | E220 itself absent (E224 added at EV-102) | ~34 / cakes, cookies-coffee, granola, bread, juices | **High** | Confirm EFSA 2022 group-ADI withdrawal + Margin-of-Exposure scope applies to E220 as class anchor, and the declared-allergen asthma threshold (≥10 mg/kg). Confirmed-harm pathway (allergen), not just observational — likely `contested`/`confirmed-negative`. Most abundant unrecognised preservative on the shelf; currently invisible to the detector. |
| 3 | **E435 / E475 / E477** (baked-goods emulsifiers) | all absent | ~44 / cakes, cookies-coffee | **High** | Whether E435 (polysorbate 60) / E475 (PGE) / E477 (PGMS) appear individually in any NutriNet-Santé wave or cohort, and whether the polysorbate-80 (E433, contested) gut-barrier mechanism extends to E435. Dominant emulsifiers on the highest-additive-burden shelf; siblings already `contested`. |
| 4 | **E422 glycerol** (humectant) | absent | ~62 / cakes, chocolate, cookies-coffee, protein bars, snacks | **Medium** | EFSA numeric ADI + any positive harm signal at food-label (not supplement) humectant doses. Highest product count but lowest evidence complexity — likely `functional`/`likely-neutral`; needs grounding, not assumption. |
| 5 | **E141 copper chlorophylls** (colour) | type-2 — existing `unclassified` row, anchor refresh | 1 / maadanim | **Low** | Targeted check: has EFSA issued a discrete post-2015 numeric ADI for the chlorophyll/chlorophyllin group? If yes → tier resolves to `functional`; if no → `unclassified` stands and is current. Fast single-opinion check, not a two-PDF commission. |

## Explicitly NOT flagged (coverage solid, or addable as maintenance without a research commission)

- **Flavour enhancers (E621/MSG):** zero on any live shelf — not a gap now.
- **Polyols** E965 maltitol (~24), E420 sorbitol (~13): `functional`/`dose-dependent` (laxative threshold); addable from existing EFSA/JECFA records, no fresh PDF.
- **E300 / E282:** already in library (rows 3/5); now confirmed live on bread/cakes — retained entries are correct, no gap.
- **E503 ammonium bicarbonate** (~57, baked goods): `functional` (decomposes/volatilises in baking) — maintenance entry, no commission.
- **E920 L-cysteine, E235 natamycin, E319 TBHQ:** 1 product each — taxonomy/maintenance entries, not commission-level (TBHQ worth an entry given IARC interest, low priority).
- **E150d:** refine the existing E150 `disclosure-gap` row when the label names class d (4-MEI then knowable) — maintenance, not commission.

## Routing

- **Tier assignment** for any commissioned item: Nutrition (after evidence lands).
- **Detector wiring:** Data (after tier).
- **Which to commission first:** Product/owner call — Nutrition recommends **#1–#3** as the high-value set.
- **Maintenance-addable items** (E503, polyols, E920, E235, E150d refinement): can be batched into the library without owner research at the next maintenance pass.
