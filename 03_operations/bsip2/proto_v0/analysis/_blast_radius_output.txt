  ew = stated_pct/100 if stated_pct else pos_weight(position)
This means pos_weight(3)=0.68 beats stated_pct=40%=0.40.
The fix: stated_pct records should ALWAYS beat position-weight records,

  1. If only one has stated_pct -> that wins unconditionally

  3. If neither has stated_pct -> higher pos_weight wins
